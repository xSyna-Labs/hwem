# xSyna HWEM

Browser-Ausgabe des xSyna-HWEM-Projekts. Die veröffentlichte Anwendung liegt als `index.html` vor und ist für die Auslieferung über einen statischen Webserver vorgesehen.

## Deployment

Die produktive HWEM-Instanz synchronisiert den `main`-Branch automatisch. Änderungen an `index.html` werden innerhalb weniger Minuten auf `hwem.xsyna.de` ausgerollt.
